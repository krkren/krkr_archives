SE Command

The [se] tag allows you to play, stop, and control sound effects.

Shorthand Notation

Unknown tag names starting with "se" are treated as both the name attribute and the play attribute of the [se] tag.
Example:
@se01 time=1000 loop
; Treated as: @se name=se01 play=se01 time=1000 loop

@se01 stop=1000
; Treated as: @se name=se01 play=se01 stop=1000
; The stop attribute takes precedence over the play attribute, so you can stop the playback of se01.
Unknown attribute names in the [se] tag are treated as values for the play attribute.
Example:
@se test time=1000
; Treated as: @se play=test time=1000

Sound Effect Playback

Attribute NameAttribute ValueDescription
playAudio FilenameStarts playback of the specified file.
storageAudio FilenameAlias for the play attribute.
startLabel NameSpecifies the playback start position. Specify the label name set in the loop tuner.
If omitted, playback starts from the beginning of the file.
looptrue/falseIf true is specified, the file will loop. Default is false.
timeTime (ms)Specifies the fade-in time. If omitted, playback starts immediately without fading.
synctrueIf true is specified, playback runs synchronously. This means it will wait for playback to finish.
Note: In the case of loop playback, it cannot wait for playback to end as it does not finish.
nosynctrueIf true is specified, playback runs asynchronously. This means it does not wait for playback to finish.
Since asynchronous execution is the default, this attribute is always ignored.
waitTime (ms)If specified, playback runs synchronously and waits for the additional specified time after finishing.
See the sync attribute section for details on synchronous execution.
canskiptrue/falseUsed with the sync or wait attributes. If false is specified, the wait for completion cannot be skipped by clicking. Default is true.
bufBuffer NumberSpecifies the buffer to use for playback by number.
nameAudio FilenameSpecifies the buffer to use for playback by filename. It plays in the buffer that is playing that file.
If the buffer playing that file does not exist, an unused buffer is automatically used.
Plays a sound effect by specifying the file name in the play attribute.
If the buffer being used is currently playing, the current file is stopped before playing.
If both the buf attribute and the name attribute are omitted, an unused buffer is automatically used.

Stop Sound Effect

Attribute NameAttribute ValueDescription
stopTime (ms)Stops the currently playing sound effect.
If the attribute value is omitted, it stops immediately. If a time is specified, it stops after fading out for that duration.
timeTime (ms)Specifies the fade time. Same as specifying a numeric value in the stop attribute.
synctrueIf true is specified, the fade-out runs synchronously. It will wait for the fade to finish.
nosynctrueIf true is specified, the fade-out runs asynchronously. It does not wait for the fade to finish. Since asynchronous execution is the default, this attribute is always ignored.
waitTime (ms)If specified, the fade-out runs synchronously and waits for the additional specified time after finishing.
See the sync attribute section for details on synchronous execution.
canskiptrue/falseUsed with the sync or wait attributes. If false is specified, the fade wait cannot be skipped by clicking. Default is true.
bufBuffer NumberSpecifies the buffer to stop by number.
nameAudio FilenameSpecifies the buffer to stop by filename. It stops the buffer that is playing that file.
Stops the currently playing sound effect using the stop attribute.
You must specify either the buf attribute or the name attribute.

Sound Effect Volume Setting

Attribute NameAttribute ValueDescription
fadeVolume % (0-100)Specifies the volume of the sound effect. The initial state is 100.
timeTime (ms)Specifies the fade time. If omitted, the volume changes to the specified level immediately.
synctrueIf true is specified, the fade runs synchronously. It will wait for the fade to finish.
nosynctrueIf true is specified, the fade runs asynchronously. It does not wait for the fade to finish. Since asynchronous execution is the default, this attribute is always ignored.
waitTime (ms)If specified, the fade runs synchronously and waits for the additional specified time after finishing. See the sync attribute section for details on synchronous execution.
canskiptrue/falseUsed with the sync or wait attributes. If false is specified, the fade wait cannot be skipped by clicking. Default is true.
bufBuffer NumberSpecifies the buffer to set the volume for by number.
nameAudio FilenameSpecifies the buffer to set the volume for by filename. It sets the buffer that is playing that file.
Sets the sound effect volume using the fade attribute. The volume is reset to 100 every time playback is started via the play attribute.
You must specify either the buf attribute or the name attribute.
