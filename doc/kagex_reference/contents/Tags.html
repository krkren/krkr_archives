Tag Reference

This is a reference for tags available in KAGEX.

Notes

KAGEX is a development version. Bugs may still exist. This also applies to this reference.
Detailed explanations of world extensions are not provided on this page, but it is assumed that the world extension is loaded as a plugin. It is loaded automatically by default.
The afterline, afterpage, dispname, donemapselect, donepanel, doneselect, interrupt, p2, preindent, and selstop tags are used internally. Do not overwrite them with macros, etc.

action ( Start Action )

Layer Operations
AttributeRequired?ValueDescription
layerno"base" or integer 0 or greater or "message0" or "message1" or "message"Specifies the target layer.
Specifying "base" results in the background layer.
Specifying an integer of 0 or greater results in the corresponding foreground layer.
Specifying "message0" or "message1" results in the message layer. If simply "message" is specified, the current target message layer specified by the current tag becomes the target.
pageno"fore" or "back"Specifying "fore" targets the fore page, and "back" targets the back page. If omitted, it is considered "fore".
targetnoTJS expressionSpecifies the target object.
Specify a TJS expression that evaluates to an object.
actionnoTJS expressionSpecifies the action to execute as an array or dictionary array.
modulenoModule nameSpecifies the action to execute by action module name.
Depending on the module, other required attributes must be specified.
moduleNamenoAction nameAlias for the module attribute.
pathno"x1,y1,opacity1,x2,y2,opacity2, ..."Specifies the action to execute using movement position and opacity, similar to the path attribute of the move tag.
Specify as a string separated only by commas, without parentheses. Alternatively, an array in this order can be specified.
splinenotrue or falseIf true is specified, the layer will move along a B-spline curved path between positions specified by the path attribute.
If false is specified, the layer will move along a linearly interpolated path between positions specified by the path attribute.
If true is specified, specify at least 2 points for the path.
If omitted, it is considered false.
timenoTime (ms)Specifies the time duration for the action execution.
Valid only when the action is specified by module (moduleName) or path attributes.
nowaitnotrue or falseThe action will not be stopped by the p tag. Also, it will not be possible to wait using the wact tag, etc. If omitted, it is considered false.
Valid only when the action is specified by module (moduleName) or path attributes.
delaynoTime (ms)Specifies the delay time before the action starts. The action will execute after the specified time. If omitted, it is considered 0.
Valid only when the action is specified by module (moduleName) or path attributes.
accelnoAccelerationSpecifies whether to perform accelerated movement.
Specifying 0 results in movement progressing at a constant rate from start to finish. If omitted, it is considered 0.
Specifying a number less than -1 causes it to start fast and gradually slow down.
Specifying a number greater than 1 causes it to start slow and gradually speed up.
You can also specify a real number.
Valid only when the action is specified by module (moduleName) or path attributes.
starttimenoTime (ms)Offsets the initial value of the internal operation time of the action by the specified value.
Valid only when the action is specified by module (moduleName) or path attributes.
hidenotrue or falseIf true is specified, the target layer will be hidden when the action ends. If omitted, it is considered false.
Valid only when the action is specified by module (moduleName) or path attributes, and a foreground layer is targeted.
nextnotrue or false
syncnotrue or falseIf true is specified, wait for the action to end. If omitted, it is considered false.
waitnoTime (ms)Wait for the action to end, and wait for an additional specified time.
However, it does not wait if skipped by a click.
Specifying this attribute sets the sync attribute to true.
canskipnotrue or falseIf true is specified, the wait can be skipped by clicking.
If false is specified, it cannot be skipped.
However, note that if click skip is prohibited by the clickskip tag, this skip is also disabled.
If skipped, it will immediately enter the state as if the action had ended.
If omitted, it is considered true.
Executes the specified action on the specified object.
Target object specification via layer and page attributes takes precedence over specification via the target attribute.
Action specification follows the order of priority: action, module, moduleName, path attributes.
The end of the action can also be waited for using the wact tag or the wat tag.
Example:
[image layer=0 storage="card" page="fore" visible=true left=100 top=100]

[eval exp="tf.dic = %[ left: %[ handler:MoveAction, value:0, time:1000]]"]
[action layer=0 action="tf.dic" sync=true]
; ↑ Example using the action attribute. Action moves foreground layer 0 to left=0

[action layer=0 module="LayerNormalMoveModule" x=100 y=100 time=1000]
; ↑ Example using the module attribute. Action moves foreground layer 0 to left=0

bgmopt ( BGM Settings )

BGM Operations
AttributeRequired?ValueDescription
volumenoVolume % (0-100)Specifies the BGM volume in %. Initial state is 100%. If omitted, the volume is not changed.
100 is the upper limit. Only suppression of volume is supported (amplification is not possible due to sound source characteristics).
gvolumenoVolume % (0-100)Specifies the BGM global volume in %. Initial state is 100%. If omitted, the volume is not changed.
The global volume is something separate from the normal volume specified by the volume attribute, allowing control of BGM volume. The actually played volume is the volume multiplied by the normal volume and global volume (e.g., if volume=50 and gvolume=75, then 50(%)*75(%)=37.5(%)).
The global volume is recorded in system variables and carried over to the next startup (it is not saved in each bookmark).
deviceno"Wave" or "MIDI" or "CDDA"Changes the BGM playback media.
The types of files that can be played change depending on the playback media.
Changes BGM settings.
Attributes that are omitted are not changed.
