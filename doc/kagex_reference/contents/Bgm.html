BGM Command

The [bgm] tag allows you to play, stop, and control BGM.
If you wish to use the fade function, please set doubleBuffered to true in Config.tjs.

Shorthand Notation

Unknown tag names starting with "bgm" are treated as the play attribute of the [bgm] tag.
Example:
@bgm01 intime=1000
; Treated as: @bgm play=bgm01 intime=1000
Unknown attribute names in the [bgm] tag are treated as values for the play attribute.
Example:
@bgm test intime=1000
; Treated as: @bgm play=test intime=1000

BGM Playback

Attribute NameAttribute ValueDescription
playAudio FilenameStarts playback of the specified file.
If the same file is already playing, nothing is done. If a different file is playing, it is stopped before starting the new one.
storageAudio FilenameAlias for the play attribute.
startLabel NameSpecifies the playback start position. Specify the label name set in the loop tuner.
If omitted, playback starts from the beginning of the file.
looptrue/falseIf true is specified, the file will loop. Default is true.
pausedtrue/falseIf true is specified, playback will pause immediately after starting. Default is false.
mvolumetrue/falseIf true is specified, plays at a volume matching the movie volume. Default is false.
noflagtrue/falseIf true is specified, the playback flag is not recorded. Default is false.
The playback flag is recorded as, for example, sf.bgm_BGM01 = true if play=bgm01 is played.
intimeTime (ms)Specifies the fade-in time. If omitted, playback starts immediately without fading.
outtimeTime (ms)Used with the intime attribute.
Specifies the fade-out time for the currently playing file. Default is 5000. Ignored if nothing is playing.
overlapTime (ms)Used with the intime attribute.
If not specified, fade-in starts after fade-out finishes. If specified, fade-in starts earlier by this amount of time.
Cannot be larger than outtime. Negative values will delay the start of the fade-in.
timeTime (ms)Specifies intime, outtime, and overlap all at once.
noxchgtrue/falseIf true is specified, the intime, outtime, and overlap attributes are ignored, and the currently playing file stops immediately without fading.
Additionally, the time attribute is treated as the fade-in time. Default is false.
synctrueIf true is specified, playback runs synchronously. This means it will wait for the fade to finish or playback to end.
If fading in, it waits for the fade-in to finish; if not, it waits for playback to finish.
Note: In the case of loop playback, it cannot wait for playback to end as it does not finish.
nosynctrueIf true is specified, playback runs asynchronously. It does not wait for the fade or playback to finish.
Since asynchronous execution is the default, this attribute is always ignored.
waitTime (ms)If specified, playback runs synchronously and waits for the additional specified time after finishing.
See the sync attribute section for details on synchronous execution.
canskiptrue/falseUsed with the sync or wait attributes. If false is specified, the wait for completion cannot be skipped by clicking. Default is true.
Plays BGM by specifying the file name in the play attribute.

BGM Stop

Attribute NameAttribute ValueDescription
stopTime (ms)Stops the currently playing BGM.
If the attribute value is omitted, it stops immediately. If a time is specified, it stops after fading out for that duration.
timeTime (ms)Specifies the fade time. This is the same as specifying a time in the stop attribute.
synctrueIf true is specified, the fade-out runs synchronously. It will wait for the fade to finish.
nosynctrueIf true is specified, the fade-out runs asynchronously. It does not wait for the fade to finish.
Since asynchronous execution is the default, this attribute is always ignored.
waitTime (ms)If specified, the fade-out runs synchronously and waits for the additional specified time after finishing.
See the sync attribute section for details on synchronous execution.
canskiptrue/falseUsed with the sync or wait attributes. If false is specified, the fade wait cannot be skipped by clicking. Default is true.
Stops the currently playing BGM using the stop attribute.

BGM Resume

Attribute NameAttribute ValueDescription

If the attribute value is omitted, it resumes immediately. If a time is specified, it resumes while fading in for that duration.
timeTime (ms)Specifies the fade time. This is the same as specifying a time in the stop attribute.
synctrueIf true is specified, the fade-in runs synchronously. It will wait for the fade to finish.
nosynctrueIf true is specified, the fade-in runs asynchronously. It does not wait for the fade to finish.

See the sync attribute section for details on synchronous execution.
canskiptrue/falseUsed with the sync or wait attributes. If false is specified, the fade wait cannot be skipped by clicking. Default is true.
Resumes the currently paused BGM using the resume attribute.

BGM Volume Setting

Attribute NameAttribute ValueDescription
fadeVolume % (0-100)Sets the volume of the BGM. The initial state is 100.
timeTime (ms)Specifies the fade time. If omitted, the volume changes to the specified level immediately.
synctrueIf true is specified, the fade runs synchronously. It will wait for the fade to finish.
nosynctrueIf true is specified, the fade runs asynchronously. It does not wait for the fade to finish.
Since asynchronous execution is the default, this attribute is always ignored.
waitTime (ms)If specified, the fade runs synchronously and waits for the additional specified time after finishing.
See the sync attribute section for details on synchronous execution.
canskiptrue/falseUsed with the sync or wait attributes. If false is specified, the fade wait cannot be skipped by clicking. Default is true.
Sets the BGM volume using the fade attribute. The volume is reset to 100 every time playback is started via the play attribute.
